# CLOSED VS OPEN RECURSION

## Closed recursion

C_rev,t+1 = f(C_rev,t)

The system self-modifies.

However:

∂C_rev / ∂E* = 0

Reality cannot modify the source of modification.

Result:

Trajectory.

The system moves through a space.

---

## Open recursion

C_rev,t+1 = f(C_rev,t,E_t*)

Reality participates in changing the system's future transformation rules.

Result:

Lineage.

The system changes the space it can evolve through.
